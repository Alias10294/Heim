# Changelog

## v0.1.0 - [Release](https://github.com/alias10294/heim/releases/tag/v0.1.0)
### Additions
- Properties library
  - core *getter* and *setter* primitives and traits
  - generic *property map* type using lambdas
- Graphs library
  - core *graph operations* primitives and traits
  - generic *adjacency list graph* type suited for many use cases
  - generic *graph algorithms* such as *BFS*, *DFS*, *Dijkstra* and more
- full documentation and complete tests
- Meson integration and *single-header* distribution
