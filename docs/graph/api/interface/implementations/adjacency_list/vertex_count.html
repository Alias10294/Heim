adjacency_list::vertex_count

Synopsis

[[nodiscard]] constexpr
size_type
vertex_count() const
noexcept;

Overview

Returns the number of vertices in *this.

Complexity

O(1)

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list<> g{{0, 1}, {2, 1}, {4, 3}, {3, 2}};
  std::print("{} ", g.vertex_count());

  g = {{0, 2}, {1, 3}, {2, 3}};
  std::print("{} ", g.vertex_count());
}

Output

5 4
