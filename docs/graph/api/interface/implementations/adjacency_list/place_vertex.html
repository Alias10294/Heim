adjacency_list::place_vertex

Synopsis

constexpr
vertex_type
place_vertex();

Overview

Creates a new vertex in *this and returns its value.

Complexity

O(1) amortized.

Exceptions

This function exhibits a strong exception safety guarantee , that is if any exception is thrown the function has no effect.

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list g{};

  auto v0{g.place_vertex()};
  std::println("{}", g.vertices());

  g.place_vertex();
  std::println("{}", g.vertices());
}

Possible Output

[0]
[1, 0]
