adjacency_list::in_edges

Defined in graph/interface/implementation/adjacency_list.hpp

Synopsis

[[nodiscard]] constexpr
auto
in_edges(vertex_type v) const
noexcept
requires is_in_incident;

Overview

Returns an unordered view of the edges in *this whose target vertex is v.

Undirected graphs

If is_directed is equal to false, this method and out_edges return equivalent ranges of edges for a given vertex, but the edges' source and target vertex are context-dependent. In this method, for example, each referenced edge's target vertex is v.

Parameters

Name Description
v The target vertex

Example

#include <print>
#include <heim/graph.hpp>

using undirected_graph = heim::adjacency_list<false>;
using directed_graph   = heim::adjacency_list<true>;

template<typename Graph>
void print_in_edges(Graph const &g, vertex_t<Graph> v)
{
  for (auto e : g.in_edges(v))
    std::print("({}, {}) ", g.source(e), g.target(e));
  std::println();
}

int main()
{
  directed_graph   dg{{0, 1}, {2, 0}, {1, 2}};
  undirected_graph ug{{0, 1}, {2, 0}, {1, 2}};

  print_in_edges(dg, 0);
  print_in_edges(ug, 0);
}

Possible output

(2, 0)
(1, 0) (2, 0)
