operator==, != (adjacency_list)

Synopsis

[[nodiscard]] friend constexpr
bool
operator==(adjacency_list const &lhs, adjacency_list const &rhs)
noexcept
= default;

operator!= is available through the language's rewritten comparison candidates.

Overview

Compares lhs and rhs for equality.

Because the comparison is defaulted, equality covers the complete stored graph state rather than graph isomorphism alone. Vertex and edge identifiers, incidence storage and the next identifiers to be assigned therefore participate in the comparison.

Parameters

NameDescription
lhs, rhsThe two adjacency_list objects to compare

Complexity

O(V + E) in the worst case, where V and E are the numbers of vertices and edges stored in the compared graphs.

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list g0{{0, 1}, {0, 2}};
  heim::adjacency_list g1{{4, 5}, {4, 6}};

  heim::adjacency_list g2{};
  auto v0{g2.place_vertex()};
  auto v1{g2.place_vertex()};
  auto v2{g2.place_vertex()};

  g2.place_edge(v0, v1);
  g2.place_edge(v0, v2);

  std::print("{} ", g0 == g1);
  std::print("{} ", g0 == g2);
  std::print("{} ", g1 == g2);
}

Output

false true false
