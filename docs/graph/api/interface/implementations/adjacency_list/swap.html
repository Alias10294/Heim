adjacency_list::swap

Synopsis

constexpr
void
swap(adjacency_list &other);
friend constexpr
void
swap(adjacency_list &lhs, adjacency_list &rhs)
{ lhs.swap(rhs); }

Overview

Exchange the contents of the *this with other.

Respects the allocator's swap propagation semantics of the standard template library.

Parameters

Name Description
other The adjacency_list whose contents to swap with *this

Complexity

O(1)

Code Example

#include <print>
#include <heim/graph.hpp>

template<typename G>
void print_edges(G const &g)
{
  for (auto e : g.edges())
    std::print("{} ", g.endpoints(e));

  std::println();
}


int main()
{
  heim::adjacency_list g0{{0, 1}, {0, 2}, {1, 2}};
  heim::adjacency_list g1{{0, 3}, {0, 1}, {1, 2}, {1, 3}};

  g0.swap(g1);
  print_edges(g0);
  print_edges(g1);
}

Possible output

(0, 3), (0, 1), (1, 2), (1, 3)
(0, 1), (0, 2), (1, 2)
