adjacency_list::operator=

Synopsis

  1. constexpr
adjacency_list &
operator=(adjacency_list const &other);
  2. constexpr
adjacency_list &
operator=(adjacency_list &&other);
  3. constexpr
adjacency_list &
operator=(std::initializer_list<std::pair<id_type, id_type>> ilist);

Overview

Replaces the vertices and edges in *this.

1)Copy assignment operator
2)Move assignment operator
3)Clears and uses the edges described by ilist

Parameters

NameDescription
otherThe other adjacency list whose contents to assign to this object
ilistThe initializer list of edges to assign to this object

Complexity

1, 2)O(V + E), where V and E are respectively the number of vertices and edges in other.
3)O(V + E + N) for multigraphs; O(V + E + N²) otherwise in the worst case, where V, E and N are the numbers of vertices, edges and elements in ilist.

Code Example

#include <utility>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list other{{0, 1}, {1, 2}};
  heim::adjacency_list g0{};
  heim::adjacency_list g1{};
  heim::adjacency_list g2{};

  g0 = other;                            // copy assignment
  g1 = std::move(g0);                    // move assignment
  g2 = {{0, 1}, {0, 2}, {1, 2}, {2, 3}}; // initializer-list assignment
}
