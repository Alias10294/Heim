adjacency_list::edge_count

Synopsis

[[nodiscard]] constexpr
size_type
edge_count() const
noexcept;

Overview

Returns the number of edges in *this.

Complexity

O(1)

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list<> g{{0, 1}, {2, 1}, {4, 3}, {3, 2}};
  std::print("{} ", g.edge_count());

  g = {{0, 2}, {1, 3}, {2, 3}};
  std::print("{} ", g.edge_count());
}

Output

4 3
