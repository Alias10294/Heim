adjacency_list::clear_vertex

Synopsis

constexpr
void
clear_vertex(vertex_type v);

Overview

Removes all edges incident with vertex v without removing the vertex itself.

Parameters

NameDescription
vThe vertex whose incident edges are removed

Preconditions

v identifies a vertex contained in *this.

Complexity

O(E + d(v)), where E is the number of edges in *this and d(v) is the degree of v.

Code Example

#include <print>
#include <heim/graph.hpp>

template<typename G>
void print_edges(G const &g)
{
  for (auto e : g.edges())
  {
    auto [u, v] = g.endpoints(e);
    std::print("({}, {}) ", u, v);
  }
  std::println();
}

int main()
{
  heim::adjacency_list g{{0, 1}, {0, 2}, {1, 0}, {1, 2}};
  print_edges(g);

  g.clear_vertex(0);
  print_edges(g);
}

Possible Output

(1, 2) (1, 0) (0, 2) (0, 1)
(1, 2)
