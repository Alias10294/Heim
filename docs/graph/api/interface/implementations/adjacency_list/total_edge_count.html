adjacency_list::total_edge_count

Synopsis

[[nodiscard]] constexpr
size_type
total_edge_count(vertex_type v) const
noexcept
requires is_in_incident && is_out_incident;

Overview

Returns the number of edges in *this incident with vertex v.

In Undirected Graphs

If is_directed is false, this method, out_edge_count and in_edge_count are equivalent and return the same value.

Parameters

NameDescription
vThe vertex whose incident edges are counted

Preconditions

v identifies a vertex contained in *this.

Return Value

The number of edges incident with v. In a directed graph, this is the sum of its incoming and outgoing edge counts.

Complexity

O(1)

Code Example

#include <print>
#include <heim/graph.hpp>

using undirected_graph = heim::adjacency_list<false>;
using directed_graph   = heim::adjacency_list<true>;

int main()
{
  directed_graph   dg{{0, 1}, {2, 0}, {1, 2}};
  undirected_graph ug{{0, 1}, {2, 0}, {1, 2}};

  std::print("{} ", dg.total_edge_count(0));
  std::print("{} ", ug.total_edge_count(0));
}

Output

2 2
