adjacency_list::place_edge

Synopsis

constexpr
std::pair<edge_type, bool>
place_edge(vertex_type u, vertex_type v);

Overview

Creates an edge between vertices u and v in *this.

In Undirected Graphs

When is_directed is true, u and v are respectively the source and target of the new edge. In an undirected graph, interchanging them has no semantic effect.

Parameters

NameDescription
uThe source vertex for the new edge
vThe target vertex for the new edge

Preconditions

Both u and v identify vertices contained in *this.

Return Value

A pair consisting of the created edge and a bool set to true if and only if an edge has been created (i.e. when is_multigraph is equal to false).

Complexity

O(1) amortized when is_multigraph is set to true, O(d(u)) or O(d(v)) otherwise.

Exceptions

This function exhibits a strong exception safety guarantee , that is if any exception is thrown the function has no effect.

Code Example

#include <print>
#include <heim/graph.hpp>

template<typename G>
void print_edges(G const &g)
{
  for (auto e : g.edges())
    std::print("{} ", g.endpoints(e));

  std::println();
}

int main()
{
  heim::adjacency_list g{{0, 1}, {0, 2}, {0, 3}};

  auto [e0, placed0]{g.place_edge(1, 2)};
  auto [e1, placed1]{g.place_edge(1, 2)};

  std::println("{} {}", placed0, placed1);
  print_edges(g);
}

Possible Output

true false
(1, 2) (0, 1) (0, 2) (0, 3)
