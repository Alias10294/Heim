adjacency_list::remove_vertex

Synopsis

constexpr
void
remove_vertex(vertex_type v);

Overview

Removes vertex v from *this, together with all edges incident with it.

Parameters

NameDescription
vThe vertex to remove

Preconditions

v identifies a vertex contained in *this.

Complexity

O(E + d(v)²) in the worst case, where E is the number of edges in *this and d(v) is the number of edges incident with v.

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list g{{0, 1}, {0, 2}};

  g.remove_vertex(0);
  std::println("{}", g.vertices());
  std::println("{}", g.edges());
}

Possible Output

[2, 1]
[]
