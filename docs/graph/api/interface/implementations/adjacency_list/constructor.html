Overview

Constructs a new adjacency list from various data sources, optionally using the allocator alloc.

1, 4)Default constructors
2, 5)Copy constructors
3, 6)Move constructors
7, 10)Construct the adjacency list with the edges in the range [first, last). If a vertex is placed later in the graph, its associated value will follow that of the largest vertex described in this range.
8, 11)Adapt 7) and 10) respectively for range objects
9, 12)Adapt 7) and 10) respectively for initializer lists

Template Parameters

NameDescription
InputItA type that models std::input_iterator and that references pairs of vertices (interpreted as edges)
RA type that models std::ranges::input_range and that references pairs of vertices (interpreted as edges)

Parameters

NameDescription
allocThe allocator to use for all memory allocations of this object
otherThe other adjacency list to use as source of initialization for this object
first, lastThe pair of iterators defining the source range of edges to initialize this object
rgThe source range of edges to initialize this object
initThe initializer list of edges to initialize this object

Complexity

1, 4)O(1).
2, 5)O(V + E), where V and E are respectively the number of vertices and edges in other.
3)O(1).
6)O(V + E) in the worst case, where V and E are respectively the number of vertices and edges in other.
7–12)O(N) for multigraphs; O(N²) in the worst case otherwise, where N is the number of edges in the input sequence.

Code Example

#include <ranges>
#include <utility>
#include <vector>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list g0{}; // default constructor
  heim::adjacency_list g1{g0}; // copy constructor
  heim::adjacency_list g2{std::move(g0)}; // move constructor

  std::vector<std::pair<unsigned, unsigned>> rg{{0, 1}, {0, 2}, {1, 2}, {2, 3}};
  heim::adjacency_list g3{rg.begin(), rg.end()}; // iterator pair constructor
  heim::adjacency_list g4{std::from_range, rg}; // range constructor
  heim::adjacency_list g5{{0, 1}, {0, 2}, {1, 2}, {2, 3}}; // initializer list constructor
}
