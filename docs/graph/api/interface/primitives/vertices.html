Overview

Returns a range referencing the graph g's vertices.

Customization point object

The call graphs::vertices(g) is equivalent to:

  1. g.vertices() if it exists,
  2. otherwise, vertices(g), where vertices is found through argument-dependent lookup (ADL).

Code Example

#include <print>
#include <heim/graph.hpp>

using graph_type = heim::adjacency_list<true>;

int main()
{
  graph_type g{{0, 1}, {1, 2}, {0, 2}, {2, 3}};

  std::print("{}", heim::graphs::vertices(g));
}

Possible Output

[3, 2, 1, 0]
