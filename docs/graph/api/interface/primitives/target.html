graphs::target

Overview

Returns the target (or head) vertex of the edge e in the graph g.

Customization point object

The call graphs::target(g, e) is equivalent to:

  1. g.target(e) if it exists,
  2. otherwise, target(g, e), where target is found through argument-dependent lookup (ADL).

In Undirected Graphs

When g does not satisfy graphs::directed, the target of an edge depends on the context in which the edge was obtained:

  • for an edge returned by graphs::out_edges(g, v), graphs::target(g, e) is the other incident vertex,
  • for an edge returned by graphs::in_edges(g, v), graphs::target(g, e) is v.

Code Example

#include <print>
#include <heim/graph.hpp>

using graph_type = heim::adjacency_list<true>;

int main()
{
  graph_type g{{0, 1}, {0, 2}, {1, 2}};

  std::print("{} ", heim::graphs::target(g, 0));
  std::print("{} ", heim::graphs::target(g, 2));
}
