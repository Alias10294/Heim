graphs::edges

Overview

Returns a range referencing the graph g's edges.

Customization point object

The call graphs::edges(g) is equivalent to:

  1. g.edges().
  2. otherwise, edges(g), where edges is found through argument-dependent lookup (ADL).

Code Example

#include <print>
#include <heim/graph.hpp>

using graph_type = heim::adjacency_list<>;

int main()
{
  graph_type g{{0, 1}, {1, 2}, {0, 2}, {2, 3}};

  for (auto e : heim::graphs::edges(g))
    std::print("{} ", heim::graphs::endpoints(g, e));
}

Possible Output

(2, 3) (0, 2) (1, 2) (0, 1)
