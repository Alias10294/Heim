Overview

Removes the edge e from the graph g without removing its incident vertices.

Customization point object

The call graphs::remove_edge(g, e) is equivalent to:

  1. g.remove_edge(e) if it exists,
  2. otherwise, remove_edge(g, e), where remove_edge is found through argument-dependent lookup (ADL).

Code Example

#include <print>
#include <heim/graph.hpp>

using graph_type = heim::adjacency_list<true>;

int main()
{
  graph_type g{{0, 1}, {0, 2}, {1, 2}};

  for (auto e : heim::graphs::edges(g))
    std::print("{} ", heim::graphs::endpoints(g, e));
  std::println();

  heim::graphs::remove_edge(g, 1);

  for (auto e : heim::graphs::edges(g))
    std::print("{} ", heim::graphs::endpoints(g, e));
  std::println();
}

Possible Output

(1, 2) (0, 2) (0, 1)
(1, 2) (0, 1)
