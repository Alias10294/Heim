graphs::endpoints

Synopsis

noexcept(/* see below */);

Overview

Returns the pair of vertices connected by the edge e in the graph g.

Customization point object

The call graphs::endpoints(g, e) is equivalent to:

  1. g.endpoints(e).
  2. otherwise, endpoints(g, e), where endpoints is found through argument-dependent lookup (ADL).
  3. otherwise, std::pair{graphs::source(g, e), graphs::target(g, e)} if graphs::source(g, e) and graphs::target(g, e) are valid expressions.

Code Example

#include <print>
#include <heim/graph.hpp>

using graph_type = heim::adjacency_list<>;

int main()
{
  graph_type g{{0, 1}, {1, 2}, {0, 2}, {2, 3}};

  for (auto e : heim::graphs::edges(g))
    std::print("{} ", heim::graphs::endpoints(g, e));
}

Possible Output

(2, 3) (0, 2) (1, 2) (0, 1)
