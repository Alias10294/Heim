graphs::is_directed

Synopsis

template<typename G>
struct is_directed
  : std::bool_constant<G::is_directed>
{ };

template<typename G>
inline constexpr bool is_directed_v
= is_directed<G>::value;

template<typename G>
concept directed
= is_directed_v<G>;

Overview

Checks if the given graph type G is a directed graph.

This trait may be specialized by users to specify the direction for a type to use as a graph type that does not provide the is_directed member constant (for example a std::vector<std::vector<int>>).
