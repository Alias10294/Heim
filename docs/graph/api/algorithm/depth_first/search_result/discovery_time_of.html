graphs::depth_first_search_result::discovery_time_of

Synopsis

[[nodiscard]] constexpr
auto
discovery_time_of(vertex_t<std::remove_cvref_t<G>> v) const;

Overview

Returns the discovery order of the vertex v.

Parameters

Name Description
v The vertex whose discovery order to return

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list     g  {{0, 1}, {0, 2}, {1, 2}, {2, 3}};
  heim::graphs::dfs_result res{heim::graphs::dfs(g, 0)};
  
  std::print("{} ", res.discovery_time_of(3));
  std::print("{} ", res.discovery_time_of(2));
}

Possible output

4 3
