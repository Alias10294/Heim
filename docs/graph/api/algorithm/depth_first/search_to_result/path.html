Overview

Returns a view over *this's predecessor map, describing the path from the target vertex to its nearest root.

Preconditions

this->reached() returns true.

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list        g  {{0, 1}, {0, 2}, {1, 2}, {2, 3}};
  heim::graphs::dfs_to_result res{heim::graphs::dfs_to(g, 0, 3)};
  
  std::print("{}", res.path());
}

Possible output

[3, 2, 1, 0]
