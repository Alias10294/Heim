Overview

Performs a depth-first traversal of the graph g, starting from one root vertex r or multiple root vertices rs, and exploring adjacent vertices as far as possible before backtracking.

Throughout its execution, the algorithm records multiple properties of the vertices:

  • Their predecessor during the traversal, that is the vertex from which they were discovered
  • Their discovery time (or order), that is the order in which they were discovered relative to the other vertices
  • Their finishing time (or order), that is the order in which the algorithm finished exploring a vertex's descendant relative to the other vertices

These properties can be collected either in a given depth_first_search_to_result object res, or in a returned depth_first_search_to_result object.

Properties

To function and produce its results, this algorithm manipulates the graph’s elements’ properties using property maps, which can be obtained either:

  • By default, in which case the algorithm allocates external storage for the related properties
  • Manually, which can be useful when properties need to originate from a specific source
  • Through the given result object (i.e. res), which already exposes some of the required maps

Complexity

O(V + E) in the worst case, where V is the number of vertices in g and E is the number of edges in g.

Code Example

#include <print>
#include <type_traits>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list g{{0, 1}, {0, 2}, {1, 2}, {2, 3}};
  
  auto r0 = heim::graphs::depth_first_search_to(g, 0, 3);
  
  if (r0.reached())
    std::println("{}", r0.path());
  
  heim::graphs::dfs_to_result r1{std::in_place_type<heim::adjacency_list<>>, 3};
  heim::graphs::dfs_to(g, r1, heim::graphs::vertices(g));
  
  if (r1.reached())
    std::println("{}", r1.path());
}

Possible output

[3, 2, 1, 0]
[3, 2, 1, 0]
