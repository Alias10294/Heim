graphs::connected_components_result::component_id_of

Synopsis

[[nodiscard]] constexpr
auto
component_id_of(vertex_t<std::remove_cvref_t<G>> v) const;

Overview

Returns the identifier of the connected component containing the vertex v.

Parameters

Name Description
v The vertex whose component identifier to return

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list    g  {{0, 1}, {1, 2}};
  heim::graphs::cc_result res{heim::graphs::cc(g)};

  std::print("{} ", res.component_id_of(0));
  std::print("{} ", res.component_id_of(2));
}

Output

0 0
