graphs::connected_components_result::component_count

Synopsis

[[nodiscard]] constexpr
auto
component_count() const;

Overview

Returns the number of connected components in the graph.

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list    g  {{0, 1}, {2, 3}};
  heim::graphs::cc_result res{heim::graphs::cc(g)};

  std::println("{}", res.component_count());
}

Output

2
