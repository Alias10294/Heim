Overview

Computes the connected components of the undirected graph g.

Properties

To function and produce its results, this algorithm manipulates the graph's elements' properties using property maps, which can be obtained either:

  • by default, where in that case the algorithm will allocate external storage for the related properties,
  • or manually, which can be useful when properties need to originate from a specific source.

These properties can after be collected either in a given connected_components_result object res, or in a returned connected_components_result object.

Template Parameters

Parameters

NameDescription

Complexity

O(V + E) in the worst case, where V is the number of vertices in g and E is the number of edges in g.

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list g{{0, 1}, {0, 2}, {1, 2}, {2, 3}};
  
  auto r0{heim::graphs::connected_components(g)};
  std::println("{}", r0.connected());
  
  heim::graphs::cc_result r1{std::in_place_type<heim::adjacency_list<>>};
  heim::graphs::cc(g, r1);
  std::println("{}", r1.connected());
}

Output

true
