Overview

breadth_first_search_to_result is a class template providing a result interface to the breadth_first_search_to algorithm.

Template Parameters

Name Description
G The related graph type
PMap The property map type used to record reached vertices' predecessor
LMap The property map type used to record reached vertices' distance to their nearest root vertex
TMap The property map type used to record reached vertices' order
