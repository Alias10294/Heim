Overview

Returns a view over *this's predecessor map, describing the path from the vertex v to its nearest root.

Parameters

NameDescription
vThe vertex whose path to view

Preconditions

this->reached(v) returns true.

Code Example

#include <print>
#include <heim/graph.hpp>

int main()
{
  heim::adjacency_list     g  {{0, 1}, {0, 2}, {1, 2}, {2, 3}};
  heim::graphs::bfs_result res{heim::graphs::bfs(g, 0)};
  
  std::print("{}", res.path_from(3));
}

Output

[3, 2, 0]
