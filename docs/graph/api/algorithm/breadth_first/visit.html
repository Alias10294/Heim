Overview

Performs a breadth-first traversal of the graph g, starting from one root vertex r or multiple root vertices rs, visiting all adjacent vertices before moving on to further vertices.

Throughout its execution, the algorithm exposes events that can be exploited by methods in the visitor vis.

Properties

To function and produce its results, this algorithm manipulates the graph's elements' properties using property maps, which can be obtained either:

  • by default, where in that case the algorithm will allocate external storage for the related properties,
  • or manually, which can be useful when properties need to originate from a specific source.

Visitor Events

This algorithm lets users customize its execution by letting visitor objects respond to specific events as member functions of said visitor objects.

Parameters

Name Description
g The graph
v A vertex of the graph
e An edge of the graph

Events

initialize_vertex(g, v)

Invoked when vertices are prepared for traversal, that is when they have just been colored in white.

Return values
  • If graphs::visit::stop is returned, the algorithm's execution is stopped.

source_vertex(g, v)

Invoked when v is recognized as one of the source vertices.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.
  • If graphs::visit::skip is returned, the algorithm ignores v entirely and does not discover it.

discover_vertex(g, v)

Invoked when v is first approached during the algorithm's traversal.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.
  • If graphs::visit::prune is returned, the algorithm abruptly finishes its exploration from v, immediately coloring it to black.

examine_vertex(g, v)

Invoked when v is dequeued, before examining its outgoing edges.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.
  • If graphs::visit::prune is returned, the algorithm abruptly finishes its exploration from v, immediately coloring it in black.

examine_edge(g, e)

Invoked for each outgoing edge e of an examined vertex, before checking for its color.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.
  • If graphs::visit::skip is returned, the algorithm's traversal ignores e entirely and does not explore its target vertex

tree_edge(g, e)

Invoked for an examined edge e whose target is white, before it is colored in gray and is discovered.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.

non_tree_edge(g, e)

Invoked for an examined edge e whose target is already colored in gray or black.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.
  • If graphs::visit::skip is returned, the algorithm's traversal avoids the gray_target(g, e)and black_target(g, e) events from being reached.

gray_target(g, e)

Invoked for a non-tree edge e if its target vertex is colored in gray (unless it has skipped by non_tree_edge(g, e).

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.

black_target(g, e)

Invoked for a non-tree edge e if its target vertex is colored in black (unless it has skipped by non_tree_edge(g, e).

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.

finish_vertex(g, v)

Invoked just after the vertex v has been colored in black, avoiding all further exploration from it.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.

Pseudocode

with a graph G and root vertices roots do
    for each vertex v in G do
        color v in white 
        emit initialize_vertex(G, v) then
            if stop then
            return false
    for each root vertex r in roots do
        emit source_vertex(G, r) then
            if stop then
                return false
            else if skip then
                continue
        color r in gray
        emit discover_vertex(G, r) then
            if stop then
                return false
            else if prune then
                color r in black
                emit finish_vertex(G, r) then
                    if stop then
                        return false
                continue
        enqueue r
    while the queue is nonempty do
        dequeue u
        emit examine_vertex(G, u) then
            if stop then
                return false
            else if prune then
                color u in black
                emit finish_vertex(G, u) then
                    if stop then
                        return false
                 continue
        for each out-edge e of u do
            emit examine_edge(G, e) then
                if stop then
                    return false
                else if skip then
                    continue
            let v the target vertex of e
            if v's color is white do
                emit tree_edge(G, e) then
                    if stop then
                        return false
                color v in gray
                emit discover_vertex(G, v) then
                    if stop then
                        return false
                    else if prune then
                        color v in black
                        emit finish_vertex(G, v) then
                            if stop then
                                return false
                        continue
                enqueue v
            else do
                emit non_tree_edge(G, e) then
                     if stop then
                         return false
                if v's color is gray do
                    emit gray_target(G, e) then
                        if stop then
                            return false
                else do
                    emit black_target(G, e) then
                        if stop then
                            return false
               color u in black
               emit finish_vertex(G, u) then
                   if stop then
                       return false

1–2) Queue must model a queue

Preconditions

q.empty() returns true.

Parameters

Name Description
g The graph to traverse

r The root vertex for the traversal
vis The visitor used to exploit the algorithm's events
cm The property map used to manage vertices’ exploration state
q The queue used to manage vertices’ exploration

Return Value

The algorithm returns a bool set to:

  • false only if it was stopped by an event returning graphs::visit::stop,
  • true otherwise.

Complexity

O(V + E) in the worst case, where V is the number of vertices in g and E is the number of edges in g.

Code Example

#include <print>
#include <heim/graph.hpp>

using graph_type  = heim::adjacency_list<>;
using vertex_type = heim::graphs::vertex_t<graph_type>;

struct visitor 
{ 
  void discover_vertex(graph_type const &g, vertex_type v)
  { std::print("{} ", v); }
};

int main()
{
  heim::adjacency_list g{{0, 1}, {0, 2}, {1, 2}, {2, 3}};
  
  heim::graphs::breadth_first_visit(g, 0, visitor{});
}

Possible output

0 1 2 3
