Overview

Performs Dijkstra's algorithm on the graph g, starting from one root vertex r or multiple root vertices rs, and finding the shortest paths to all other vertices through weighted edges. Provided by the property map wm, weights have to be non-negative.

Throughout its execution, the algorithm exposes events that can be exploited by methods in the visitor vis.

Properties

To function and produce its results, this algorithm manipulates the graph's elements' properties using property maps, which can be obtained either:

  • by default, where in that case the algorithm will allocate external storage for the related properties,
  • or manually, which can be useful when properties need to originate from a specific source.

Visitor Events

This algorithm lets users customize its execution by letting visitor objects respond to specific events as member functions of said visitor objects.

Parameters

Name Description
g The graph
v A vertex of the graph

Events

initialize_vertex(g, v)

Invoked when vertices are prepared before traversal.

Return values
  • If graphs::visit::stop is returned, the algorithm's execution is stopped.

source_vertex(g, v)

Invoked when v is recognized as one of the source vertices.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.
  • If graphs::visit::skip is returned, the algorithm ignores v entirely and does not discover it.

discover_vertex(g, v)

Invoked when v is first discovered during the algorithm's traversal.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.

examine_vertex(g, v)

Invoked when v is extracted from the heap, before examining its outgoing edges.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.
  • If graphs::visit::prune is returned, the algorithm abruptly finishes its exploration from v, immediately coloring it in black.

examine_edge(g, e)

Invoked for each outgoing edge e of an examined vertex, before its eventual relaxation.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.
  • If graphs::visit::skip is returned, the algorithm's traversal ignores e entirely and does not explore its target vertex

relaxed_edge(g, e)

Invoked when e was relaxed, that is when the traversal found a shorter path to its target vertex through it.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.

non_relaxed_edge(g, e)

Invoked when e was not relaxed, that is when the traversal did not found a shorter path to its target vertex through it.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.

finish_vertex(g, v)

Invoked just after the vertex v has been colored in black, avoiding all further exploration from it.

Return values
  • If graphs::visit::stop is returned, the algorithms's execution is stopped.

Pseudocode

dijkstra_visit(G, roots) do
    for each vertex v in G do
        color v in white
        set v's distance to infinity
        emit initialize_vertex(G, v) then
            if stop then
                return false
    for each root vertex r in roots do
        emit source_vertex(G, r) then
            if stop then
                return false
            else if skip then
                continue
        set r's distance to 0
        color r in gray
        emit discover_vertex(G, r) then
            if stop then 
                return false
        insert r in the heap
    while the heap is nonempty do
        extract u from the heap
        emit examine_vertex(G, u) then
            if stop then
                return false
            else if prune then
                color u in black
                emit finish_vertex(G, u) then
                    if stop then
                        return false
                continue
        for each out-edge e of u do
            emit examine_edge(G, e) then
                if stop then
                    return false
                else if skip then
                    continue
            let v be e's target vertex
            let d be u's distance + the e's weight
            if d < current distance of v then
                set v's distance to d
                emit relaxed_edge(G, e) then
                    if stop then 
                        return false
                if v's color is white
                    color v in gray
                    emit discover_vertex(G, v) then
                        if stop then 
                            return false
                    insert v in the heap
                else if v's color is gray
                    heapify-up v
            else do
                emit non_relaxed_edge(G, e) then
                    if stop then 
                        return false
        color u in black
        emit finish_vertex(G, u) then
            if stop then
                return false
    return true

Return Value

The algorithm returns a bool set to:

  • false only if it was stopped by an event returning graphs::visit::stop,
  • true otherwise.

Complexity

O((V + E)log(V)) in the worst case, where V is the number of vertices in g and E is the number of edges in g.

Code Example

#include <print>
#include <unordered_map>
#include <heim/graph.hpp>

using graph_type  = heim::adjacency_list<>;
using vertex_type = heim::graphs::vertex_t<graph_type>;
using edge_type   = heim::graphs::edge_t  <graph_type>;

struct visitor
{ 
  std::unordered_map<vertex_type, unsigned> &d;
  
  void examine_vertex(graph_type const &, vertex_type v) const
  { std::println("{} (distance: {})", v, d[v]); }
};

int main()
{
  graph_type                                g{};
  std::unordered_map<edge_type  , unsigned> w{};
  std::unordered_map<vertex_type, unsigned> d{};
  
  auto const v0{heim::graphs::place_vertex(g)};
  auto const v1{heim::graphs::place_vertex(g)};
  auto const v2{heim::graphs::place_vertex(g)};
  auto const v3{heim::graphs::place_vertex(g)};
  
  auto const [e0, placed]{heim::graphs::place_edge(g, v0, v1)}; w[e0] = 1;
  auto const [e1, _     ]{heim::graphs::place_edge(g, v0, v2)}; w[e1] = 10;
  auto const [e2, _     ]{heim::graphs::place_edge(g, v1, v2)}; w[e2] = 2;
  auto const [e3, _     ]{heim::graphs::place_edge(g, v2, v3)}; w[e3] = 1;
  
  heim::graphs::dijkstra_visit(
      g, v0, heim::make_property_map(w),
      visitor{d}, heim::make_property_map(d));
}
