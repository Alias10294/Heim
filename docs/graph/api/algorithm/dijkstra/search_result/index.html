Overview

dijkstra_search_result is a class template providing a result interface to the dijkstra_search algorithm.

Template Parameters

Name Description
G The related graph type
WMap The property map type used to access edges' weights
PMap The property map type used to record reached vertices’ predecessors
DMap The property map type used to record distances from vertices to their nearest root vertex
Inf The type of the value representing the distance to unreachable vertices
Cmp The function type used to compare vertices' distancesn
