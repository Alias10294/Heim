Overview

Produces a reversed topological sort of the directed graph g, that is a linear ordering of g's vertices such that for every directed edge with source vertex u and target vertex v, v comes before u in the ordering.

Properties

To function and produce its results, this algorithm manipulates the graph's elements' properties using property maps, which can be obtained either:

  • by default, where in that case the algorithm will allocate external storage for the related properties
  • or manually, which can be useful when properties need to originate from a specific source.

Template Parameters

Name Description
G The graph type
OutIt The output iterator type to the start of the range where the ordering will be outputted
CMap The property map type used to manage vertices’ exploration state during the algorithm's execution

Parameters

Name Description
g The graph whose vertices to order
it The output iterator to the start of the range where the ordering will be outputted
cm The property map used to manage vertices’ exploration state during the algorithm's execution

Complexity

O(V + E) in the worst case, where V is the number of vertices in g and E is the number of edges in g.

Code Example

#include <iterator>
#include <print>
#include <vector>
#include <heim/graph.hpp>

using graph_type  = heim::adjacency_list<true>;
using vertex_type = heim::graphs::vertex_t<graph_type>;

int main()
{
  graph_type               g   {{0, 1}, {0, 2}, {1, 2}, {2, 3}};
  std::vector<vertex_type> topo{};
  
  heim::graphs::reverse_topological_sort(g, std::back_inserter(topo));
  std::println("{}", topo);
}

Output

[3, 2, 1, 0]
