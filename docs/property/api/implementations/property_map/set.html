property_map::set

Overview

Invokes this's setter function object with k as its first argument and args as its following arguments.

Template Parameters

NameDescription
KThe key type
ArgsThe value type pack

Parameters

NameDescription
kThe key whose associated property is assigned to
argsThe value pack

Code Example

#include <cstddef>
#include <print>
#include <vector>
#include <heim/property.hpp>

int main()
{
  std::vector<int>   vec   {0, 2, 4};
  auto               setter{[&vec](std::size_t const k; int v) { vec[k] = v; }};
  heim::property_map pm    {heim::no_property_getter, setter};

  std::print("{} ", vec[0]);
  pm.set(0, 1);
  std::print("{} ", vec[0]);
}

Output

0 1
