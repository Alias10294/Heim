Overview

Constructs a property_map object with special getters and setters according to certain tags and arguments.

Name Description
identity_arg Creates a readable map that returns as property its argument unchanged
constant_arg Creates a readable map that returns the same value no matter the key
associative_container_arg Creates a map that references the given associative container
random_access_iterator_arg Creates a map that associates keys with elements of a random-access sequence by using them, directly or through a given index map, as offsets from the given iterator
random_access_range_arg Creates a map that associates keys with elements of the given random-access range by using them, directly or through a given index map, as offsets
member_arg Creates a map that maps objects to one of their member objects or to the return type of one of their nullary member functions
pointer_arg Creates a map that maps pointers to their pointed-to object
invocable_arg Creates a map that maps objects to the result of the given function with them as the argument
composable_arg Creates a map that composes the two given property maps

Code Example

#include <map>
#include <ranges>
#include <utility>
#include <vector>
#include <heim/property.hpp>

int main()
{
  using pair = std::pair<int, int>;

  std::map<int, int> map{};
  std::vector<int>   vec{};
  auto               it {vec.begin()};

  auto pm1 {heim::make_property_map(heim::identity_arg)};                           // 1.
  auto pm2 {heim::make_property_map(heim::constant_arg, 10.};                       // 2.
  auto pm3 {heim::make_property_map(heim::associative_container_arg, map)};         // 3.
  auto pm4 {heim::make_property_map(heim::random_access_iterator_arg, it)};         // 4.
  auto pm5 {heim::make_property_map(heim::random_access_iterator_arg, it , ac_pm)}; // 5.
  auto pm6 {heim::make_property_map(heim::random_access_range_arg   , vec)};        // 6.
  auto pm7 {heim::make_property_map(heim::random_access_range_arg   , vec, ac_pm)}; // 7.
  auto pm8 {heim::make_property_map(heim::member_arg, &pair::first)};               // 8.
  auto pm9 {heim::make_property_map(heim::pointer_arg)};                            // 9.
  auto pm10{heim::make_property_map(heim::invocable_arg, std::ranges::size)};       // 10.
  auto pm11{heim::make_property_map(heim::composable_arg, ac_pm, ri_pm)};           // 11.
}
