random_access_range_arg

Synopsis

struct random_access_range_arg_t { explicit random_access_range_arg_t() = default; }

inline constexpr random_access_range_arg_t random_access_range_arg{};

Overview

Used with make_property_map to create a property map that associates keys with elements of a random-access range by using them, directly or through an index map, as offsets.

Code Example

#include <print>
#include <vector>
#include <heim/property.hpp>
int main()
{
  std::vector<int> vec{0, 2, 4, 5, 8};
  auto             pm {heim::make_property_map(heim::random_access_range_arg, vec)};

  std::print("{} ", pm.get(0));
  std::print("{} ", pm.get(3));
  
  pm.set(3, 6);
  std::print("{} ", pm.get(3));
}

Output

0 5 6
