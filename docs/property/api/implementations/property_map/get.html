property_map::get

Synopsis

template<typename K>
[[nodiscard]] constexpr
decltype(auto)
get(K &&k);
template<typename K>
[[nodiscard]] constexpr
decltype(auto)
get(K &&k) const;

Overview

Invokes this's getter function object with k as its argument and returns its exact result.

Template Parameters

NameDescription
KThe key type

Parameters

NameDescription
kThe key whose associated property is accessed

Code Example

#include <cstddef>
#include <print>
#include <vector>
#include <heim/property.hpp>

int main()
{
  std::vector<int>   vec   {0, 2, 4};
  auto               getter{[&vec](std::size_t k) { return vec[k]; }};
  heim::property_map pm    {getter, heim::no_property_setter};

  std::print("{} ", pm.get(0));
  std::print("{} ", pm.get(1));
  std::print("{} ", pm.get(2));
}

Output

0 2 4
