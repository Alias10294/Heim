properties::is_writable_map_for

Synopsis

template<typename M, typename K, typename ...Args>
struct is_writable_map_for;

template<typename M, typename K, typename ...Args>
inline constexpr bool is_writable_map_for_v
= is_writable_map_for<M, K, Args ...>::value;

template<typename M, typename K, typename ...Args>
concept writable_map_for
= is_writable_map_for_v<M, K, Args ...>;

Overview

Checks whether instances of the property map type M can modify properties with keys of type K and value arguments of types Args.

Template Parameters

NameDescription
MThe property map type
KThe key type
Args ...The value type pack
