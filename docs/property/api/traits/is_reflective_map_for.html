properties::is_reflective_map_for

Synopsis

template<typename M, typename K>
struct is_reflective_map_for;

template<typename M, typename K>
inline constexpr bool is_reflective_map_for_v
= is_reflective_map_for<M, K>::value;

template<typename M, typename K>
concept reflective_map_for
= is_reflective_map_for_v<M, K>;

Overview

Checks whether instances of the property map type M can access properties with keys of type K and write back to properties with the accessed objects' type.

Template Parameters

NameDescription
MThe property map type
KThe key type
